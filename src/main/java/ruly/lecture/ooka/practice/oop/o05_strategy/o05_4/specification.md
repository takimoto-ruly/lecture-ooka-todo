## SNSメッセージ送信とプライバシーフィルター

### 【概要】
個人アカウントや企業アカウント（継承）が、投稿メッセージに対して「通常公開」「伏字（フィルター）」などの公開設定（Strategy）を動的に切り替えて送信するシステムを構築します。

### 【仕様】
1. **フィルターのインターフェース（Strategy）**
   - **抽象メソッド**: 引数として投稿本文（`String`）を受け取り、加工後の文字列（`String`）を返す。
2. **具体的なフィルタークラス（Concrete Strategy）**
   - クラスA（フィルターなし）: 本文をそのまま返す。
   - クラスB（プライバシー）: 本文に含まれる「秘密」という単語を「***」に置換して返す（`replace` メソッド等を使用）。
3. **親クラス：アカウント（Superclass）**
   - **フィールド**: アカウント名（文字列）、現在のフィルター（1のインターフェース型）。
   - **メソッド1**: フィルターを変更する（setter）。
   - **メソッド2**: 引数として本文（`String`）を受け取り、現在のフィルターを適用した文字列を返す。
4. **子クラス：特定のアカウント（Subclass / 多態性の検証用）**
   - クラスA（一般ユーザー）: 親を継承。投稿メソッド（引数：本文 `String`）を持ち、親のフィルターを通した文字列の先頭に「[一般] 」を付与して返す。
   - クラスB（公式アカウント）: 親を継承。投稿メソッド（引数：本文 `String`）を持ち、親のフィルターを通した文字列の先頭に「【公式】」を付与して返す。
