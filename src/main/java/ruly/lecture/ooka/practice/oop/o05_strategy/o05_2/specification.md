## RPGのキャラクターと魔法属性の切り替え

### 【概要】
戦士や魔法使いといったキャラクター（継承）が、武器や魔法に付与する「属性（炎、氷）」を自由に切り替えて（Strategy）、敵に異なる効果の攻撃（多態性）を与えるシステムを構築します。

### 【仕様】
1. **属性効果のインターフェース（Strategy）**
   - **抽象メソッド**: 引数として基本ダメージ（`int`）を受け取り、属性効果を乗せた最終ダメージ（`int`）を返す。
2. **具体的な属性クラス（Concrete Strategy）**
   - クラスA（炎属性）: 基本ダメージを **1.5倍** にした値を返す（端数切り捨て）。
   - クラスB（氷属性）: 相手の動きを鈍らせるため、基本ダメージをそのまま（**1.0倍**）返す。
3. **親クラス：キャラクター（Superclass）**
   - **フィールド**: 名前（文字列）、現在の属性効果（1のインターフェース型）。
   - **コンストラクタ**: 名前と属性効果を受け取って初期化する。
   - **メソッド**: 属性効果を途中で変更する（setter）。
4. **子クラス：特定の職業（Subclass / 多態性の検証用）**
   - クラスA（戦士）: 親を継承。攻撃メソッド（引数なし、戻り値 `int`）を実装し、自身の基本ダメージ `40` をベースに現在の属性効果を適用した最終ダメージを計算して返す。
   - クラスB（魔法使い）: 親を継承。攻撃メソッド（引数なし、戻り値 `int`）を実装し、自身の基本ダメージ `60` をベースに現在の属性効果を適用した最終ダメージを計算して返す。
