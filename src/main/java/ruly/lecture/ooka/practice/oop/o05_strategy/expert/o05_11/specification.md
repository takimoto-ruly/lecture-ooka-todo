## 次世代自動物流システムとマルチStrategy出荷エンジン

### 【概要】
商品の「ピッキング（在庫引当）処理」と「検品・梱包（追加費用）計算」という2つの独立したStrategyを組み合わせ、商品（親）➔ 精密機器（子）➔ スマートフォン（孫）の多階層を通じて、注文処理と最終出荷費用を算出するシステムを構築します。

### 【仕様】
1. **在庫引当戦略（Strategy 1）**
   - **入力**: 注文数量（整数型）、複数の倉庫に格納されている現在の在庫数リスト（`List<Integer>`）
   - **出力**: 引当の成否（真偽値型）
   - **アルゴリズムA（単一倉庫優先引当）**: リスト内の倉庫を順番に確認し、1つの倉庫だけで注文数量をすべて賄える場所が1つでも存在すれば成功、どこにも存在しなければ失敗とする。
2. **梱包追加費用戦略（Strategy 2）**
   - **入力**: 商品価格（整数型）、配送先地域（文字列型）
   - **出力**: 追加の梱包手数料（整数型）
   - **アルゴリズムB（地域・価格連動梱包）**: 配送先地域が「離島」に該当する場合のみ一律 `3,000` 円の手数料を発生させる。それ以外の地域は一律 `500` 円とする。ただし、商品の価格自体が `50,000` 円以上である高額商品の場合は、地域に関わらずこの追加手数料は常に `0` 円（無料）となる。なお、価格が負の数の場合は例外を投げる。
3. **クラス階層（親・子・孫）**
   - **親クラス**: 商品名、基本価格、2つのStrategyを保持する。在庫引当の判定、および最終出荷費用（基本価格 + 梱包手数料）を算出する。
   - **子クラス**: 親を継承。出荷費用算出処理において、親クラスが算出した費用に対して、さらに一律「精密機器専用保険料 1,500円」を加算して返す。
   - **孫クラス**: 子を継承。出荷費用算出処理において、子クラスが算出した費用に対して、さらに一律「アクティベーション技術手数料 800円」を加算して返す。
