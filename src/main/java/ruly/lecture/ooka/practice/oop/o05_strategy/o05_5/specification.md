## スマート家電と省エネモードの切り替え

### 【概要】
エアコンや照明などのスマート家電（継承）が、「通常モード」「省エネモード」といった動作戦略（Strategy）を切り替えることで、それぞれの家電に応じた消費電力を一括で計算（多態性）します。

### 【仕様】
1. **動作モードのインターフェース（Strategy）**
   - **抽象メソッド**: 引数として基準消費電力（`int`）を受け取り、モード適用後の消費電力（`int`）を返す。
2. **具体的なモードクラス（Concrete Strategy）**
   - クラスA（通常モード）: 基準電力をそのまま（**1.0倍**）返す。
   - クラスB（省エネモード）: 基準電力を **半分（0.5倍）** にした値を返す（端数切り捨て）。
3. **親クラス：スマート家電（Superclass）**
   - **フィールド**: 家電名（文字列）、現在の動作モード（1のインターフェース型）。
   - **コンストラクタ**: 家電名と動作モードを受け取って初期化する。
   - **メソッド1**: 動作モードを変更する（setter）。
   - **メソッド2（抽象メソッド、または上書き前提）**: 現在の消費電力を計算して返す（戻り値 `int`）。
4. **子クラス：具体的な家電（Subclass / 多態性の検証用）**
   - クラスA（エアコン）: 親を継承。消費電力計算メソッドを実装し、自身の基準電力 `1000` に対し、現在の動作モードを適用した値を返す。
   - クラスB（スマート照明）: 親を継承。消費電力計算メソッドを実装し、自身の基準電力 `100` に対し、現在の動作モードを適用した値を返す。
