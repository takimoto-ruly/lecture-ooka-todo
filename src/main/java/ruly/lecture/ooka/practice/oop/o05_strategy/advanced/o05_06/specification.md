## 次世代物流システムにおける多階層配送料計算エンジン

### 【概要】
配送業者やルートを表す「配送戦略（Strategy）」を動的に切り替え、荷物の基本属性（親）、配送種別（子）、そして特殊配送（孫）の階層構造を用いて、堅牢な多態性による料金計算システムを構築します。

### 【仕様】
1. **配送料計算の戦略（Strategy）**
   - **抽象メソッド**: 引数として「商品の配送重量（`double`）」を受け取り、計算された配送料（`int`）を返す。
   - **具象戦略A（エコノミー便）**: `重量 × 150円` を配送料とする（端数切り捨て）。
   - **具象戦略B（プレミアム特急便）**: `重量 × 500円 + 固定優先手数料 2,000円` を配送料とする。
   - **防衛処理**: 重量に `0` 以下の値が渡された場合は `IllegalArgumentException` を投げる。
2. **親クラス：荷物ベース（Superclass）**
   - **フィールド**: 追跡ID（`String`）、重量（`double`）。コンストラクタでのみ設定され、変更不可（不変）とする。
   - **メソッド**: 引数として「配送料計算の戦略」を受け取り、その戦略が算出した配送料をそのまま返す。
3. **子クラス：配送種別（Subclass）**
   - **具象子クラスA（一般混載便荷物）**: 親を継承。親クラスの計算結果をそのまま返す。
   - **具象子クラスB（クール冷凍便荷物）**: 親を継承。料金計算メソッドをオーバーライドし、親クラスの計算結果（配送料）に対して常に「一律冷凍管理費 1,200円」を加算して返す。
4. **孫クラス：特殊配送（Sub-subclass）**
   - **具象孫クラスB-1（クール冷凍便・離島宛て）**: `クール冷凍便荷物（子）` をさらに継承。料金計算メソッドをオーバーライドし、子クラスが算出した総配送料（管理費込）に対して、離島中継手数料として **1.5倍**（端数切り捨て）にした金額を最終料金として返す。
