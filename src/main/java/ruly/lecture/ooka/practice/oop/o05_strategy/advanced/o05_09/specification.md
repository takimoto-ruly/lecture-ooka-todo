## スマートホーム・マルチレイヤー電力制御システム

### 【概要】
エアコンなどのスマート家電において、エコモードやパワーモード（Strategy）を動的に切り替え、スマート家電（親）➔ 空調家電（子）➔ 床暖房付き高級空調（孫）の多階層で、極めて緻密な消費電力のバリデーションと集計を行います。

### 【仕様】
1. **動作モードの戦略（Strategy）**
   - **抽象メソッド**: 基準消費電力（`int`）を引数に受け取り、モード適用後の消費電力（`int`）を返す。
   - **具象戦略A（セービングモード）**: 基準電力を **0.6倍** に抑えた値を返す（端数切り捨て）。
   - **具象戦略B（ブーストモード）**: 基準電力を **1.5倍** に高めた値を返す（端数切り捨て）。
2. **親クラス：スマート家電（Superclass）**
   - **フィールド**: デバイス名（`String`）、基準消費電力（`int`）。
   - **メソッド**: 「動作モードの戦略」を引数に受け取り、戦略が適用された消費電力を返す。
3. **子クラス：家電カテゴリ（Subclass）**
   - **具象子クラス（空調メイン暖房）**: 親を継承。消費電力計算メソッドをオーバーライドし、空調はコンプレッサーの常時起動電力として、戦略適用後の電力に一律 `200` Wを固定加算して返す。
4. **孫クラス：複合機能製品（Sub-subclass）**
   - **具象孫クラス（プレミアム床暖房連動空調）**: `空調メイン暖房（子）` を継承。メソッドをオーバーライドする。この孫クラスは、現在「床暖房が稼働中か（`boolean`）」の状態（フィールド）を持つ。床暖房が稼働中（`true`）の場合のみ、子クラスの計算結果に対してさらに `500` Wを加算して返す。稼働していない場合は、子クラスの計算結果をそのまま返す。
