## RPGのAI戦闘システムと環境適応ダメージ

### 【概要】
「ターゲット選定」と「気候によるダメージ補正」の2つのStrategyを使用し、基本モンスター（親）➔ 魔法系エネミー（子）➔ 伝説の魔王（孫）の多階層で最終ダメージを算出します。オーバーライドの連鎖により、行動メッセージと最終ダメージを多態的に変化させます。

### 【仕様】
1. **ターゲット選択戦略（Strategy 1）**
   - **入力**: プレイヤー全員の現在HPリスト（`List<Integer>`）
   - **出力**: 攻撃対象となるプレイヤーのインデックス番号（整数型）
   - **アルゴリズムA（瀕死者優先狙い）**: リストを解析し、現在HPが **「0より大きい（生存している）プレイヤー」の中で最もHPが低い** プレイヤーのインデックス番号を特定して返す。
2. **環境補正戦略（Strategy 2）**
   - **入力**: モンスターの攻撃属性（文字列型）、現在のステージの気候（文字列型）
   - **出力**: ダメージの補正倍率（浮動小数点数型）
   - **アルゴリズムB（属性シナジー補正）**: 攻撃属性が「FIRE」かつ気候が「SUNNY」である場合は `2.0` 倍、属性が「ICE」かつ気候が「RAIN」である場合は `1.5` 倍の倍率とする。それら以外の組み合わせの場合は、一律 `1.0` 倍の倍率とする。
3. **クラス階層（親・子・孫）**
   - **親クラス**: モンスター名、基本攻撃力、攻撃属性、2つのStrategyを保持する。ターゲット選択と環境補正を実行し、「[モンスター名]の攻撃: [インデックス番号]番目に[最終ダメージ]のダメージ！」という文字列メッセージを生成して返す。
   - **子クラス**: 親を継承。メッセージ生成処理において、親クラスが算出した文字列の末尾に対して、さらに固有テキスト「（魔法障壁を展開）」を結合した文字列を返す。
   - **孫クラス**: 子を継承。メッセージ生成処理において、子クラス（および親クラス）が算出したメッセージ内のダメージ数値部分のみを **3倍** に書き換え、さらにメッセージ全体の先頭に「【絶望】」という特殊なプレフィックスを付与した最終的な戦闘ログ文字列を生成して返す。
