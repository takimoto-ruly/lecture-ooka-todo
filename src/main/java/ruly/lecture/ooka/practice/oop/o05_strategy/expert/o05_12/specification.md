## 国際サブスクリプション決済と多重セキュリティ検証

### 【概要】
「為替変換」と「アクセスセキュリティ（IP）チェック」の2つのStrategyを連携させ、アカウント（親）➔ プレミアム会員（子）➔ 法人マルチプラン（孫）の多階層で決済処理を行います。割引やライセンス倍率の多態性を表現し、安全な課金を行います。

### 【仕様】
1. **為替変換戦略（Strategy 1）**
   - **入力**: 外貨ベースの金額（浮動小数点数型）、通貨コード（文字列型）
   - **出力**: 変換後の日本円額（整数型・端数切り捨て）
   - **アルゴリズムA（多通貨変換）**: 通学コードが「USD」であれば金額を `150` 倍、「EUR」であれば `160` 倍して日本円に換算する。これら以外のサポート対象外の通貨コードが指定された場合は、即座に例外をスローする。
2. **セキュリティ戦略（Strategy 2）**
   - **入力**: 直近のアクセスIPアドレスの履歴リスト（`List<String>`）
   - **出力**: 安全性の確認結果（真偽値型）
   - **アルゴリズムB（危険識別子走査）**:  
   IPアドレスの履歴リスト内を検証し、以下のいずれかに該当する場合は不安全（`false`）を返す。すべて安全なものであれば安全（`true`）を返す。
     - 一つでも `"BLOCKED_"` という文字列から開始されている要素が存在する場合
     - システム固有のブラックリストIPである `"999.999.999.999"` と完全一致する要素が存在する場合
3. **クラス階層（親・子・孫）**
   - **親クラス**: ユーザーID、登録外貨額、IP履歴リスト、2つのStrategyを保持する。セキュリティ検証を行い、安全でない場合は決済拒否の例外をスローし、安全であれば為替変換後の日本円金額をそのまま決済額として返す。
   - **子クラス**: 親を継承。決済額算出処理において、親クラスが算出した日本円金額から一律 **10%引き**（端数切り捨て）にした優待価格を計算して返す。
   - **孫クラス**: 子を継承。このクラスは固有の属性として「契約ライセンス数（整数型）」を保持する。決済額算出処理において、子クラスが算出した割引後の価格に対して、さらに「契約ライセンス数」を掛け合わせた総額を最終的な決済金額として計算して返す。
