## 金融マルチレイヤー・タックス計算システム

### 【概要】
国内外の投資商品をモデル化し、課税アルゴリズム（Strategy）をランタイムで切り替えながら、資産（親）➔ 投資信託（子）➔ レバレッジ型特殊信託（孫）の多階層で正確な税引き後利益を算出します。

### 【仕様】
1. **課税アルゴリズムの戦略（Strategy）**
   - **抽象メソッド**: 引数として利益（`int`）を受け取り、税額（`int`）を返す。
   - **具象戦略A（国内課税モード）**: 利益の一律 **20%** を税額とする（端数切り捨て）。
   - **具象戦略B（国際優遇課税モード）**: 利益が 100,000円 以下の場合は非課税（`0` 円）、それを超えた分に対してのみ **10%** を税額とする（端数切り捨て）。
2. **親クラス：金融資産（Superclass）**
   - **フィールド**: 資産名（`String`）、運用利益（`int`）。利益が負の数の場合は `IllegalArgumentException` を投げる。
   - **メソッド**: 「課税戦略」を引数で受け取り、`運用利益 - 戦略から得た税額`（税引き後利益）を返す。
3. **子クラス：投資商品カテゴリ（Subclass）**
   - **具象子クラス（投資信託ファンド）**: 親を継承。税引き後利益の計算メソッドをオーバーライドし、信託報酬（運営費用）として一律 `500` 円をさらに差し引いた金額を返す。
4. **孫クラス：特殊運用商品（Sub-subclass）**
   - **具象孫クラス（レバレッジ型・投資信託ファンド）**: `投資信託ファンド（子）` を継承。運用利益の判定時に、この孫クラスは常に「設定されたレバレッジ倍率（`int`）」を利益に掛け合わせてから、子・親のロジックへ委ねるようにオーバーライドする（コンストラクタでレバレッジ倍率、例えば2倍などを指定）。
