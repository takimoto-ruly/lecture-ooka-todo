# Java オブジェクト指向高度包括演習（マルチStrategy＆多階層設計編）

## 共通ルール
1. `../実装ルール.md` に完全準拠すること（アクセス修飾子の適切なカプセル化、フィールドの隠蔽、不変性の意識、バリデーションなど）。
2. **包括的必須要件**：すべての課題において、以下の要素が密に連携する構造を設計してください。
   - 大枠のデータ構造や基底ライフサイクルを管理する「親クラス」
   - カテゴリごとの共通処理を定義する「子クラス」
   - さらに具体的な個別仕様や追加フックを埋め込む「孫クラス」
   - 処理のアルゴリズムを交換可能にする**「2つの異なる役割のStrategy（戦略）インターフェース」**
3. **名前の設計**：具体的なクラス名、インターフェース名、メソッド名は一切記載していません。ドメインモデルを適切に表現する英語名をご自身で設計してください。
4. **堅牢性（例外処理）**：不正な引数（負の数、`null`、空文字、リストのインデックス範囲外など）に対しては、適切なJava標準例外をスローしてください。
