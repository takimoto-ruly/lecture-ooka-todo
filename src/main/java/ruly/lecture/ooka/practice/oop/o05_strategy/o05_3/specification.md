## 乗り物シミュレーターと走行ルートの選定

### 【概要】
自動車やバイク（継承）が、「一般道」「高速道路」といったルート（Strategy）を自由に切り替えて、移動にかかる料金や時間を計算するシミュレーターです。

### 【仕様】
1. **走行ルートのインターフェース（Strategy）**
   - **抽象メソッド**: 引数として距離（整数型 `int`）を受け取り、ルートに応じた通行料金（整数型 `int`）を返す。
2. **具体的なルートクラス（Concrete Strategy）**
   - クラスA（一般道）: 通行料金は一律 `0` 円を返す。
   - クラスB（高速道路）: 「距離 × 20」円の通行料金を返す。
3. **親クラス：乗り物（Superclass）**
   - **フィールド**: ナンバー（文字列）、現在の走行ルート（1のインターフェース型）。
   - **メソッド**: 走行ルートを変更する（setter）。
4. **子クラス：特定の乗り物（Subclass / 多態性の検証用）**
   - クラスA（乗用車）: 親を継承。料金計算メソッド（引数：距離 `int`）を持ち、現在の走行ルートによる通行料金をそのまま返す。
   - クラスB（大型トラック）: 親を継承。料金計算メソッド（引数：距離 `int`）をオーバーライドし、大型車は高速料金が1.5倍になるため、ルートによる通行料金を **1.5倍**（端数切り捨て）にして返す。
