## ゲームAI：多階層ステータスと動的戦闘戦術

### 【概要】
キャラクターの戦闘スタイル（Strategy）を動的に変更し、基本エネミー（親）➔ ボスクラス（子）➔ 最終形態ボス（孫）へとオーバーライドの連鎖を利用して行動メッセージと最終攻撃力を動的に変化させます。

### 【仕様】
1. **戦闘戦術の戦略（Strategy）**
   - **抽象メソッド**: 基本攻撃力（`int`）を引数に受け取り、戦術補正後の攻撃力（`int`）を返す。
   - **具象戦略A（通常戦闘戦術）**: 基本攻撃力をそのまま（**1.0倍**）返す。
   - **具象戦略B（決死の捨身戦術）**: 基本攻撃力を **2.5倍** にした値を返す（端数切り捨て）。
2. **親クラス：基本エネミー（Superclass）**
   - **フィールド**: 個体名（`String`）、基本攻撃力（`int`）。
   - **メソッド**: 引数として「戦闘戦術」を受け取り、戦術補正後の攻撃力を計算して「[個体名] の攻撃：[補正後攻撃力] ダメージ！」という文字列を返す。
3. **子クラス：ボス級（Subclass）**
   - **具象子クラス（エリアボス）**: 親を継承。メソッドをオーバーライドし、親クラスが算出した文字列の末尾に、ボス特有の威圧効果として「（周囲にプレッシャーを放っている）」を結合して返す。
4. **孫クラス：特殊形態（Sub-subclass）**
   - **具象孫クラス（覚醒形態エリアボス）**: `エリアボス（子）` を継承。メソッドをオーバーライドし、覚醒状態を表現するため、子クラスに処理を渡す前に**「基本攻撃力を一律 +50」**した状態で親・子の計算を実行させ、最終的な文字列の先頭に「【覚醒】」を付与して返す。
