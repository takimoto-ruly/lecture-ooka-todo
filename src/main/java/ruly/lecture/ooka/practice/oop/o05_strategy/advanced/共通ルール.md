# Java オブジェクト指向高度包括演習（中級・多階層設計編）

## 共通ルール
1. `../実装ルール.md` に完全準拠すること（適切なアクセス修飾子、フィールドの隠蔽、不変性の意識、コンストラクタによるバリデーションなど）。
2. **包括的必須要件**：すべての課題において、以下の要素が密に連携する構造を美しく設計してください。
   - 共通の基底データと大枠のライフサイクルを管理する「親クラス」
   - カテゴリごとの共通処理をオーバーライドする「子クラス（抽象クラスまたは具象クラス）」
   - さらに具体的な個別仕様やフック処理を埋め込む「孫クラス」
   - 実行時のコンテキストに応じてアルゴリズムを安全に動的交換する「Strategyパターン」
3. **堅牢性（例外処理）**：不正な引数（負の数、`null`、空文字など）や、不正な状態でのメソッド呼び出しに対しては、適切なJava標準例外（`IllegalArgumentException`, `IllegalStateException` など）を即座にスローする防衛的プログラミングを行ってください。
4. **名前の設計**：具体的なクラス名、インターフェース名、メソッド名は一切記載していません。ドメインモデルを適切に表現する英語名をご自身で設計してください。
