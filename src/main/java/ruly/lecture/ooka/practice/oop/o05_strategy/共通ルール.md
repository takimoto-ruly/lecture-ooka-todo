# Java オブジェクト指向包括演習：継承・多態性・Strategyパターン

## 共通ルール
1. `../実装ルール.md` に準拠すること（適切な命名規則の選定、カプセル化の徹底など）。
2. **包括的設計**：すべての問題において、「親クラスを継承した子クラスの作成（継承）」「親の型でまとめて扱う処理（多態性）」「インターフェースを差し替えて振る舞いを変える構造（Strategyパターン）」の3つをすべて組み合わせて実装してください。
3. **名前の設計**：仕様書内で具体的な英語名は指定していません。Javaの標準的な命名規則（PascalCase, camelCase）に則り、役割がひと目でわかる適切な名前をご自身で設計してください。
